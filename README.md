# SINKA｜五幣合約掃描與模擬交易

純 HTML、CSS、JavaScript 單頁網站，適合放在 GitHub Pages。無需 Python、套件、API 金鑰或 OKX 登入；只讀公開市場行情，不會送出真實委託。

## 功能

- 同時掃描 BTC、ETH、SOL、XRP、DOGE 的 USDT 永續合約。
- 顯示多方、空方或觀望訊號、即時價格，以及依 ATR 計算的參考停損與止盈價。
- 以 EMA(9/21) 趨勢交叉、RSI(14) 篩選、1 ATR 停損與 1.5 ATR 止盈回測最近最多 300 根已收線 K 線，顯示歷史樣本勝率與樣本筆數。
- 建立模擬多單或空單，設定模擬保證金、槓桿與手續費；每 10 秒更新行情和未實現損益。
- 手動平倉，或價格觸及停損／止盈時自動平倉；交易紀錄保存在目前瀏覽器的 localStorage。

## 使用

1. 開啟 GitHub Pages 網址，等待五個幣種的行情與 K 線載入。
2. 選擇掃描週期、單邊費率、模擬保證金與槓桿。
3. 查看各幣的方向、計畫進場、停損、止盈及歷史勝率。若回測筆數少於 5 筆，頁面會標示樣本不足。
4. 按「模擬做多」或「模擬做空」建立模擬持倉；在持倉表按「平倉」可記錄手動出場。

## 計算限制

歷史勝率是有限 K 線樣本內的回測結果，不是未來預測，也不保證獲利。即時價位及損益為 OKX 公開行情估算，可能受網路延遲、滑價、資金費、強平與成交差異影響；頁面不執行真實交易。模擬資料只存在目前瀏覽器，不會同步到其他裝置，清除瀏覽器資料也會移除紀錄。
